## 🧩 Featured Projects

### 🔐 SignFlow AI — Document Signing SaaS Platform

A secure SaaS platform for document signing, workflow management, encryption, audit tracking, and AI-powered document processing.

**Tech Stack:** React.js, TypeScript, Node.js, PostgreSQL, Docker

* Secure e-signature and document workflow system
* AES-GCM client-side encryption for sensitive documents
* Audit tracking for document actions and user activity
* AI-based document processing to reduce manual work
* Tenant-based architecture with Docker deployment

---

### 📄 DocsMove — AI Document Workflow Platform

An AI-powered document management platform for editing, collaboration, e-signatures, OCR, and workflow automation.

**Tech Stack:** Next.js, TypeScript, Node.js, PostgreSQL, Docker, AI Document Processing

* Drag-and-drop signature placement on PDF documents
* AI-based OCR for scanned documents and images
* Secure document storage and role-based access control
* Activity tracking for document workflows
* Real-time collaboration features like user presence and editing status

---

### 💬 Beep Pakistan — Secure Communication Platform

A secure real-time communication platform with messaging, voice calls, video calls, and WebRTC-based communication.

**Tech Stack:** React.js, Node.js, Socket.IO, WebRTC, LiveKit

* Real-time chat and communication workflows
* Voice and video calling features
* WebRTC communication using LiveKit
* STUN/TURN configuration for stable connections
* Secure and scalable communication architecture

---

### ⚖️ CourtBank — Legal Case Management System

A legal case management platform designed for banks, courts, lawyers, and legal teams.

**Tech Stack:** React Native, Node.js, PostgreSQL, Docker

* Case tracking and legal workflow management
* Role-based access control
* Data separation for different user roles
* Digital replacement for manual legal processes
